# TaskFlow
### Простой менеджер задач для Android

TaskFlow — мой проект, который я сделал для удобного управления повседневными задачами. Хотелось создать что-то своё, чем можно пользоваться на телефоне, а не просто очередной учебный проект.

Идея довольно простая: открываешь приложение, добавляешь задачи и отмечаешь то, что уже сделал. Без лишних кнопок и сложного интерфейса.

## О проекте

Я решил сделать TaskFlow, потому что хотел попробовать разработать полноценное приложение, начиная с серверной части и заканчивая запуском на Android.

Для меня было важно не только написать код, но и разобраться, как всё работает вместе: сервер, база данных, интерфейс и само приложение.

## Технологии

| Технология | Для чего |

## Как запустить

### Android

Если у вас уже есть APK, всё довольно просто:

1. Скачайте `TaskFlow.apk`.
2. Откройте файл на Android.
3. Разрешите установку, если телефон попросит.
4. Установите и откройте TaskFlow.

Если APK подключается к backend, сервер должен быть запущен и доступен телефону.

### Backend — Spring Boot

Для запуска серверной части понадобится исходный проект, Java и PostgreSQL.

1. Откройте папку проекта в IntelliJ IDEA.
2. Дождитесь загрузки Maven.
3. Создайте базу данных PostgreSQL.
4. Укажите данные подключения в `application.properties`.
5. Откройте `TaskFlowApplication.java`.
6. Запустите приложение через **Run**.

При стандартной настройке Spring Boot сервер работает на `http://localhost:8080`.

Порт может отличаться, если он изменён в настройках.

## Как я делал TaskFlow

Начал с обычной идеи — сделать приложение для задач. Сначала разобрался со структурой проекта, потом перешёл к Spring Boot.

После этого занялся базой данных и основной логикой. Нужно было сделать так, чтобы задачи сохранялись и с ними можно было нормально работать.

Дальше перешёл к интерфейсу. Не хотел делать слишком перегруженный дизайн, поэтому старался оставить только самое необходимое.

Когда основная часть была готова, начал разбираться с Android-версией и запуском APK.

## Что оказалось сложным

Больше всего пришлось повозиться с настройкой и соединением разных частей приложения.

Иногда проблема была в настройках, иногда — в коде. Бывали моменты, когда всё выглядело правильно, но приложение всё равно не запускалось.

Особенно непросто было разобраться с подключением к базе данных и запуском Android-приложения.

Приходилось проверять ошибки, менять код и запускать всё заново.

Но именно на таких моментах я многому научился.
