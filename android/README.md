# TaskFlow для Android

Готовый APK находится в `build/TaskFlow.apk`. Требуется Android 7.0 или новее. APK открывает интерфейс работающего сервера TaskFlow. При первом запуске используется `http://192.168.1.69:8080`.

Если сервер недоступен, на экране подключения можно выбрать «Повторить» или «Изменить адрес». Если компьютер перезагрузился, сначала запустите `start-taskflow.cmd` в корне проекта. APK версии 1.0.1 можно установить поверх версии 1.0.0, сохранив данные приложения.

HTTP доступен для локального IPv4 и localhost. Для сервера за пределами локальной сети укажите HTTPS с действительным сертификатом.

Для пересборки установите JDK, платформу Android SDK 35 и Build Tools 36.0.0. Задайте `JAVA_HOME` и `ANDROID_HOME`, затем из папки `android` выполните:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build-apk.ps1
```

При первой сборке скрипт создаёт локальный ключ подписи в `.signing`. Храните этот каталог для последующих обновлений установленного приложения.
